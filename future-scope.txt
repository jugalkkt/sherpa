Sherpa: Future Scope (after the v1 core build in plan.md)
==========================================================

- Unit + integration tests
    - pytest suite with a FakeLLM (scripted responses / tool calls) so each node can be tested deterministically
    - Pure-logic tests: progress_coach status transitions and routing, option shuffling, quiz validation,
      SourceRegistry citation stripping, chunk ids and ingest-manifest idempotency
    - Graph tests: approval reject -> replan loop, interrupt/resume with the same quiz questions, needs_review path,
      all-done -> END, using an in-memory checkpointer
    - Smoke test (marked, opt-in) against the real Kaggle Ollama endpoint: doctor + one short session

- LLM eval harness
    - Small golden set of learning goals + notes for scoring curriculum quality (topic coverage, prerequisite order,
      objective testability)
    - Quiz validity checks: answer-key accuracy, groundedness in the explanation, distractor plausibility,
      duplicate detection across attempts
    - Grading accuracy: feedback correctness and weak-objective detection compared against hand labels
    - Explainer groundedness: share of claims backed by cited sources; citation validity rate
    - Track metrics across prompt/model changes (e.g. qwen2.5:7b vs other Ollama models, temperature sweeps)

- Tracing / observability
    - LangSmith or Langfuse tracing of every node, LLM call and tool call (inputs, outputs, latency, tokens)
    - Per-session dashboards: tool-call counts, retries, structured-output repair rate, tunnel failures
    - Correlate traces with the session_id / thread_id from the SQLite checkpointer

- Session report export
    - Markdown report at session end: goal, approved curriculum, per-topic status, attempts and scores
    - Weak objectives and misconceptions per topic, plus the needs_review topics with suggested next steps
    - Links to the sources cited in each explanation
    - Command such as: python -m sherpa report <session_id> [--out reports/<id>.md]
